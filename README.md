# Olá, sou o João Pedro Quevedo

Estudante de Cloud & DevOps, em transição de carreira do comércio/vendas para a área de tecnologia, com foco em AWS. Atualmente construindo experiência prática através de projetos aplicados, com interesse em seguir na área de FinOps e otimização de custos em nuvem.

---

## Habilidades AWS Desenvolvidas

| Área | Habilidades |
|---|---|
| Computação | EC2, Auto Scaling, Elastic Load Balancing, EBS |
| Armazenamento & Banco de Dados | S3 (versionamento), Snapshots de EBS, Migração de RDS |
| Rede | VPC, Route 53 (failover), Flow Logs |
| Automação & IaC | CloudFormation (YAML), Terraform, Lambda (serverless) |
| Monitoramento & Governança | CloudWatch, SNS, AWS Config, CloudTrail, Tagging de Recursos |
| Gestão de Custos | Rightsizing de EC2, Otimização de Custos, AWS Pricing Calculator |
| Segurança & Identidade | IAM (MFA, políticas de grupo), Security Groups |
| CLI & Scripting | AWS CLI, JMESPath, Python (Boto3), PHP SDK |
